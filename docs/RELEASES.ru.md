# Сборка и публикация релиза

[English](RELEASES.md) | Русский

## Запуск на GitHub

Файл workflow должен находиться в основной ветке репозитория.

1. Откройте Actions → Build vector release → Run workflow.
2. Укажите новый тег, например `vector-v1`.
3. Оставьте `publish` выключенным, чтобы скачать результат из Actions, или включите его для публикации релиза после успешных автоматических проверок.

Workflow создаёт SVG из исходных PNG, выполняет проверки и упаковывает результат. Артефакты Actions хранятся 14 дней.

При публикации проверяются контрольные суммы файлов, создаётся черновик релиза, загружаются файлы и публикуется релиз. Уже существующий тег использовать нельзя. Если загрузка прервалась, перед повторным запуском проверьте, не остался ли черновик.

Для публикации используется временный `GITHUB_TOKEN` с разрешением `contents: write`.

## Файлы релиза

- `metal-cat-master.svg` — векторный мастер с пятью цветовыми слоями.
- `manifest.json` — тег релиза и SHA исходного коммита.
- `metal-cat-<tag>.zip` — полный комплект: SVG, растровое изображение, сравнения высотой 1254 / 627 / 314 пикселей, фрагменты для визуальной проверки, отчёты и манифест.
- Для каждого файла — отдельная контрольная сумма: `metal-cat-master.svg.sha256`, `manifest.json.sha256` и `metal-cat-<tag>.zip.sha256`.

Можно скачать отдельный файл или весь комплект в ZIP. Для проверки скачайте соответствующий файл `.sha256` в ту же папку и выполните:

```sh
sha256sum -c metal-cat-master.svg.sha256
```

Перед публикацией новой сборки проверьте на изображениях семь струн, семь валов колков, семь ручек колков и кошачью форму лап. Проверка XML контролирует структуру SVG. Результаты визуальной проверки приведены в `HARD_CHECK.md`.

## Локальная сборка

Требуются Python 3 с поддержкой venv и системная библиотека Cairo.

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/build_vector.py --epsilon .1
.venv/bin/python scripts/verify_vector.py
.venv/bin/python scripts/package_release.py --tag vector-v1
```

Файлы сохраняются в `dist/vector-v1/`. Локальная сборка не публикует релиз.
