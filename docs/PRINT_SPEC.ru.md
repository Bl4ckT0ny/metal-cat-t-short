# Техническое задание на печать

[English](PRINT_SPEC.md) | Русский

## Утверждённый рисунок

Необходимо сохранить:

- узнаваемый облик мейн-куна;
- кошачью форму лап;
- позу;
- силуэт семиструнной гитары;
- одежду;
- общую композицию.

## Способ печати

Шелкография на чёрной футболке, пять печатных красок. Чёрные участки рисунка по возможности образует сама ткань. Для передачи объёма шерсти и теней используется полутоновый растр.

## Цветовые ориентиры для типографии

В таблице указаны цвета сплошных заливок из `scripts/build_vector.py`.
Они соответствуют пяти цветовым слоям и служат исходными ориентирами для подбора красок.

| Слой | sRGB HEX | sRGB R / G / B | CIELAB L* / a* / b* (D65, 2°) |
|---|---|---|---|
| DARK_GRAY | `#626466` | 98 / 100 / 102 | 42.3 / −0.4 / −1.4 |
| CREAM | `#FFF6E5` | 255 / 246 / 229 | 97.2 / 0.2 / 9.2 |
| BROWN | `#B78659` | 183 / 134 / 89 | 59.7 / 13.4 / 31.5 |
| ORANGE | `#FF831F` | 255 / 131 / 31 | 67.7 / 41.7 / 68.5 |
| RED | `#FF1608` | 255 / 22 / 8 | 53.9 / 78.4 / 65.5 |

Координаты Lab рассчитаны из sRGB для белой точки D65 и стандартного наблюдателя 2°, с округлением до десятых. Это цифровые ориентиры макета, а не измерения печатных красок и не эквиваленты Pantone. Если типография измеряет цвет относительно D50, перед сравнением значения нужно привести к одной белой точке.

### Подбор и согласование красок

1. Для каждого слоя подобрать физический образец Pantone Solid Coated или образец из системы текстильных красок типографии. Записать точный код и издание веера либо производителя, серию и рецептуру краски.
2. Напечатать сплошные плашки и шкалы полутонов на той же чёрной ткани, из которой изготовлена футболка. Добавить характерные наложения цветов из рисунка. Оценивать образец после закрепления краски.
3. Согласовать необходимость подложки. В макете пять цветовых слоёв; дополнительная белая подложка требует отдельного решения и может увеличить число печатных форм.
4. Утвердить физическую цветопробу как эталон тиража. Зафиксировать ткань, рецептуры красок, подложку, порядок печати и режим закрепления. Если приёмка проводится прибором, согласовать условия измерения и допустимое отклонение ΔE00 от утверждённого образца.

Номера Pantone и рецептуры красок **пока не утверждены**. Суффиксы C/U у Pantone обозначают бумагу, на которой напечатан образец, а не характеристику ткани: [пояснение Pantone](https://support.pantone.com/en/what-does-the-terms-coated-and-uncoated-mean-in-the-pantone-graphics-system).

Прозрачность в SVG описывает экранный вид. Передачу полутонов растром и наложение красок проверяют на цветопробе; процент прозрачности не является пропорцией смешивания краски. Для печати используются пять отдельных красок, поэтому обычный пересчёт в CMYK не задаёт их рецептуру.

## Размер и размещение

Основной макет рассчитан на максимальную предусмотренную область печати.

- Размер рисунка для футболки размера 52: **44 × 55 см**.
- Размещение: крупный принт спереди, почти на всю доступную ширину.
- Нижний край рисунка: примерно **10 см выше подола**.
- Верхний край: примерно **5–6 см ниже воротника**, с учётом конкретной футболки.

Окончательные размеры и отступы определяются по реальному изделию с учётом печатного стола и рамы типографии.

## Масштабирование

- Редактируемый векторный мастер хранится в максимальном размере.
- Меньшие варианты получают пропорциональным уменьшением мастера.
- Увеличение уменьшенного растрового изображения для крупной печати не допускается.
- Толщина линий, зазоры и размер точек должны соответствовать минимальным значениям, которые воспроизводит оборудование типографии.
- Полутоновый растр формируется или проверяется для **окончательного физического размера отпечатка**, выбранной сетки и линиатуры (LPI). Произвольное масштабирование готового растра не допускается.
- Если доступная область печати меньше 44 × 55 см, макет пропорционально уменьшают до допустимого размера.

## Комплект для печати

- Растровый эталон высокого разрешения с прозрачным фоном.
- Пять цветоделённых форм.
- Редактируемый векторный мастер SVG.
- PDF, подготовленный к печати.
- Пример размещения рисунка на футболке.
- Настройки совмещения красок и перекрытия их границ по требованиям типографии.
