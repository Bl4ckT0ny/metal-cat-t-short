# Кот-металлист — принт для футболки

[English](README.md) | Русский

Подготовка утверждённого рисунка с мейн-куном и гитарой к шелкографии.

## Требования к макету

- Чёрная футболка: ткань служит фоном и образует чёрные участки рисунка.
- Пять печатных красок: тёмно-серая, кремовая, коричневая, оранжевая и красная.
- Полутоновый растр для передачи шерсти, объёма морды и теней.
- Прозрачный фон за пределами рисунка.
- Раздельные формы для каждой краски.
- Редактируемый векторный мастер, PDF для печати и пример размещения на футболке.
- Размер основного макета: **44 × 55 см**, для футболки размера 52.

Мастер создаётся в максимальном предусмотренном размере. Для меньшей области печати его пропорционально уменьшают.

Утверждённые образ кота, гитара, поза, одежда и композиция сохраняются. Допустимы технические работы: очистка контуров, сокращение палитры, векторизация, цветоделение и подготовка к печати.

Подробные требования: [техническое задание на печать](docs/PRINT_SPEC.ru.md).

## Структура репозитория

- `master/` — исходные растровые изображения.
- `separations/` — формы для отдельных красок.
- `vector/` — векторный мастер.
- `print/` — файлы для печати.
- `preview/` — проверочные изображения и примеры размещения.
- `docs/` — требования, инструкции и результаты проверок.

## Сборка и публикация

В Git хранятся исходные PNG и скрипты. SVG и проверочные изображения создаются при сборке и публикуются как файлы релиза.

[Инструкция по сборке и публикации](docs/RELEASES.ru.md).

[Результаты проверок и источники геометрии](docs/HARD_CHECK.ru.md).

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/build_vector.py --epsilon .1
.venv/bin/python scripts/verify_vector.py
.venv/bin/python scripts/package_release.py --tag vector-v1
```

Сборка создаёт SVG с пятью цветовыми слоями без растровых вставок. Полутона заданы прозрачностью; растр для шелкографии не сформирован. Контуры фигуры получены из эталона, семиструнный гриф и головка грифа — из выбранного изображения для реконструкции.

Количество струн, валов и ручек колков, а также форму кошачьих лап проверяют визуально. Автоматическая проверка контролирует структуру SVG.
